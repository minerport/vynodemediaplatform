# Playlists

Playlists are private, explicitly ordered user queues. They are not collections. Entries have their own identity and may reference Movies or Episodes, which permits deliberate duplicates. Reordering persists positions and navigation returns the previous and next entry without wrapping.

Playback progress remains the normal per-user logical-media progress; playlists do not create a parallel resume model. Removing a playlist never removes media.
